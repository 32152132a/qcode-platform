关于 QCode 与开发者

QCode 是曲永庆基于 OpenCode / OpenWork 集成与定制的团队 AI 工作平台，支持集中管理与客户端本地执行。

平台介绍

QCode 采用服务端统一管理、客户端本地执行的架构，面向团队提供多模型接入、模型网关、账号权限、API Key 安全管理、用量配额，以及共享 Skill 和知识资料分发。

曲永庆负责平台集成与定制开发，实践涵盖 Electron 桌面客户端定制、Windows 安装包构建和 Docker / Nginx 服务端部署。

QCode 基于 OpenCode / OpenWork 开源底座开展开发，上游项目的作者及许可信息以各项目声明为准。

开发者

曲永庆（quyongqing），有 7 年前端开发经验，目前主要做 AI 应用和 AI Agent 平台开发，具备前端、Node.js 后端及部署维护经验。
