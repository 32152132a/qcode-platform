# 前端组件规则

- 页面优先只负责组件组合、配置项、数据传入和业务事件，不在页面堆叠局部样式。
- 优先复用参考项目的 src/layout、src/components/qyq-table、src/components/qyq-form 及同类组件；接口状态、分页和生命周期逻辑优先放入 hooks。
- 配色、字号、间距、圆角优先使用现有全局样式和设计变量，删除重复声明、不必要的覆盖与无意义样式。
- 视觉样式与内部交互由组件维护；已有组件不满足时先判断是否值得扩展，避免页面重复手写。
- 必要的布局、响应式和可访问性样式可以保留，不能为了零样式破坏功能或交互。
- 公共组件或全局样式扩大修改范围时先取得用户同意；确实不能复用时说明原因与替代方案。
