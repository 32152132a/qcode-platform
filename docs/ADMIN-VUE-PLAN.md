# 管理端 Vue 改造评估（尚未实施）

采用 Vue 3 + Vite + Element Plus，组件覆盖表单、可搜索选择器、弹窗、表格和分页；沿用现有品牌资源与间距设计。管理端约十来个功能页面，属于中等规模前端改造。仅引入组件库不能自动改造现有通过 DOM 创建的表单，页面交互及状态需要迁移。

保留 Node 后端接口、SQLite 数据、权限、模型网关和员工端安装/更新流程。新增独立管理端源码目录，构建产物由现有服务托管；调整前端构建与 Docker 打包，不需要改模型转发协议或员工安装包。不能通过运行时 CDN 加载依赖，否则内网部署容易受网络影响。

建议先完成模型、Key 和用户管理，再迁移部门、Skill、知识库、统计、日志及配置页面。逐页验收权限、保存校验、登录续期和手机布局，最后替换原管理页面。此方案涉及整体前端架构和构建流程，按照 AGENTS.md 需先取得用户同意，当前仅做评估。
