# 知识库与个人资料

企业知识库采用 SQLite 保存原始上传文件、知识文章及整批草稿／发布快照。对话使用 Tree-RAG 目录导航和正文读取，向量检索未接入当前流程。

## 企业知识管理

管理页包含“知识管理”和独立的“问答测试”两个页签。

目录树顶部提供上传资料和批量管理。支持 TXT、Markdown、文字型 PDF、DOCX、XLSX，文件由程序解析为基础目录、正文和短摘要，上传不调用整理模型。新增和替换共用上传接口；替换携带目标文章ID和当前草稿版本，保留文章身份。替换过程会核对文章是否被其他操作修改。

文章可下载为 Markdown，在外部编辑后上传替换。阅读预览支持标题、段落、列表、表格和代码块。文章删除和批量删除均先写入草稿，原文件继续用于来源追溯。删除前列出文章及其下级文章的影响清单，删除后调整上级目录概述，页面显示待删除标记和变更清单。

页面提供整体 AI 美化，文章菜单提供单篇美化。模型先读取相关正文，再提出目录、标题、摘要和正文组织建议。需要保留金额、日期、否定、适用范围和例外。节点来源必须有保留位置或明确的排除原因；这项检查表示来源处理记录完整，语义是否准确仍需结合原文判断。

AI 美化完成后直接保存草稿，不弹出建议确认框。左侧目录用新增、修改、删除标记影响范围，右侧统一以已发布版本与当前草稿对照标题、目录、摘要和完整正文。首次上传显示新增，未发布即被删除的文章不出现在目录中，剔除与合并原因保留在 AI 整理记录中。管理员可以查看后发布，也可以直接发布全部。保存时重新核对版本，失败不会部分写入。父目录概述最多600字符，文章摘要最多100字符，正文沿用每节12000字符限制。

发布全部会二次确认，提供“先去美化”和“直接发布”，发布本身不调用模型。程序在一个 SQLite 事务中切换整个发布版本，正文、目录和删除操作同时生效。未完成或失败的上传任务会阻止发布，可以先重试或移除失败任务。

## 问答测试

测试只使用已发布知识库，与上传、草稿和美化流程独立。每行一个问题，批量顺序执行，支持停止和单题重试。每批问题固定知识版本，期间发生发布时提示重新开始，避免混用版本。

测试复用知识整理模型的渠道配置和现有模型请求／用量记录，显示回答、引用来源、调用次数、实际 Token 和耗时。回答优先显示“有依据／依据不足”及引用原文；耗时、调用次数、Token 和目录选择与正文读取路径收进展开区。每题最多6轮调用，正文累计读取最多24000字符，相同正文不重复返回。引用必须逐字属于本题已经读取的内容。证据不足时明确说明。

关键词搜索是单独的确定性文本匹配，搜索已发布标题、摘要和正文，最多返回30项。模型问答通过目录导航定位，不自动切换向量检索。

多轮美化和测试接口采用 JSON 空白心跳及取消信号，避免等待期间触发反向代理读超时。客户端关闭操作或停止测试时取消当前请求。

## Skill 与客户端读取

内置 qcode-knowledge Skill 指导用户无需选择知识库即可检索。知识正文通过账号绑定的 MCP 工具读取：

- knowledge_catalogue：返回企业和本机个人目录，小目录完整返回，大目录按层级和游标读取。
- knowledge_read：每次1～6个节点，自动附带父级条件及文件、版本和位置。
- memory：在本机记忆开关开启时按明确要求读取或更新。

企业库对客户端保持现有文档／节点接口格式，发布版本会进入节点ID，发布后旧节点不能继续读取。真实 Agent 是否恰当触发 Skill 仍需模型实测，管理端测试用于检查知识检索与回答链路。

## 个人资料与记忆

个人资料继续由服务器解析、生成摘要后下载到本机，最多10份。下载后校验来源和版本、原子写入本机目录，再确认清理服务器临时任务。服务器按账号身份隔离临时任务，本机按网关和账号创建身份隔离资料。

本机保留目录JSON、原文件和章节Markdown，可以查看和编辑。个人记忆默认关闭，每人一份 memory.md，最多2000字符，不保存整段聊天。开启时按用户明确要求维护，写入携带内容版本以防覆盖。

个人资料和模型请求会涉及网络传输，本机保存不等于相关内容从不发送给模型。用户电脑里的资料不由服务端删除。

## 存储与验证

knowledge-tree.sqlite 与业务数据库位于同一数据目录。documents／versions 保存原文件与个人任务；library_versions／library_state 保存企业草稿和发布快照；library_imports 记录统一导入目标。AI 整理原因随草稿快照保存。

备份应覆盖整个知识库数据库及其一致的WAL状态，不能只备份业务数据库。文件和备份不提交到Git。

专项验证：

- test/knowledge-runtime.test.js：上传、替换、发布、权限、文件解析及个人下载。
- test/knowledge-library.test.js：快照持久化、来源覆盖、目录循环、并发替换及引用检查。
- test/tree-rag.test.js：独立原型中的检索预算与引用行为。

服务端库的结构检查和模拟模型测试不能替代真实模型的语义质量验证。
