# 最小知识库

管理员在“知识库”页面手动上传 UTF-8 TXT / Markdown，支持编辑、启用、禁用、删除和关键词搜索预览。第一版全员共享，最多 30 篇，每篇最多 64 KB。不支持 PDF、网页抓取、部门隔离和语义检索。

## 实现与使用

资料复用现有 SQLite skills 存储和客户端 Skill 同步机制，没有新增数据库表、向量引擎或依赖。每篇资料生成一个托管 Skill，正文保存为 references/document.md。普通 Skill 管理接口不能修改知识库资料，写入仅允许管理员，操作记录进入审计日志。

后台关键词搜索用于预览匹配结果；AI 通过 Skill 描述发现资料，再读取参考文件，并非每次请求自动注入全部正文。模型是否选择资料及引用质量仍需要真实员工试用确认。

员工不需要重新安装。资料随现有同步机制下发，重新启动客户端可保证新资料被发现。禁用或删除后，客户端下次成功同步会移除对应托管目录，不删除个人文件；已进入会话的资料内容不会被追溯清除。后台已有登录会话可能需要重新登录才能取得新增知识库权限。
