# Windows 网页登录最小改动

- 桌面和开始菜单以隐藏 PowerShell 调用 bin/desktop.ps1；启动异常弹出说明。命令行 qcode 仍默认 TUI；qcode web / qcodeweb 使用网页登录。
- 新增 web-login.mjs，监听随机的 127.0.0.1 端口，随机启动口令放在 URL fragment，进入页面后从历史地址删除。Host、Origin 和口令均验证，登录体限制 8 KB，不启用跨域访问。
- 浏览器只提交账号密码并获取状态/本地工作台地址，网关 access/refresh Token 不返回浏览器、不放在命令行。继续使用 Windows DPAPI 加密保存 session.json。
- 复用现有 auth/login、auth/me、续期接口和 launcher.mjs。第一次网页登录后自动打开工作台；保存登录失效时回到表单；已保存的有效登录直接启动。
- 重复双击复用当前本地服务。本地启动链接也通过 DPAPI 保存为 web-launch.json，退出时清理，完整卸载同时清理。
- 后台运行中的客户端可通过 qcode logout 撤销登录，现有心跳停止内核；浏览器标签关闭不等于退出后台服务。登录页提供关闭入口。
- 自动升级重启用进程内 QCODE_WEB_LOGIN_CHILD 标记避免嵌套网页启动器；不修改用户全局环境变量，不修改 OpenCode 核心源码。
- 安装与卸载识别新的隐藏启动快捷方式，保留旧 ZIP/快捷方式兼容。Inno 使用 Windows 用户临时目录编译 EXE，再归档到正式产物目录，解决本机 D 盘资源写入失败。

## 验证

网页登录专项验证来源隔离、口令、请求大小、密码错误、保存会话与启动失败。完整回归通过。

真实 Windows + 编译的 OpenCode 内核：浏览器输入员工账号后进入工作台，DPAPI 存储检查没有明文 Token，第二次启动免登录。390px 登录页面、小眼睛实测通过。测试使用隔离网关、临时账号和项目，不涉及生产 Key。

发布后员工需更新安装包一次，已安装的旧客户端不会因后台重启自动获得新启动页面。

EXE 验收检测到本机已有正式安装时，编译同一负载的独立测试 AppId；真实安装及卸载测试使用该包，原正式注册项不受影响。测试 manifest 标记 installerTestAppId，客户端发布脚本和服务器均拒绝发布此类包。
