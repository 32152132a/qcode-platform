# 套餐使用额度

套餐对用户展示“使用额度”，内部按人民币计价；1 元对应 1000 使用额度，不称为 Token。套餐售价仍显示人民币，包含额度分别设置。新建套餐默认包含 5000 使用额度、有效期 30 天；默认免费套餐的可用模型由管理员选择。有效期结束后剩余额度不可使用，不结转。

用户端仅展示剩余额度和到期日期。免费套餐有效期内不能重复领取；付费套餐可以重新申请续费。续费、升级都沿用现有全价人工核款流程，确认开通后开始新周期，旧剩余额度不结转。不做补差价、自动续费或永久钱包。

## 计价

- 对话模型固定配置普通输入、缓存输入、输出三项单价，单位为元/百万 Token。
- 收费只使用上游返回的输入和输出数量。只有明确返回的缓存命中 Token 才享受缓存折扣；没有缓存明细时按普通输入价。推理 Token 不重复加到输出总量。
- 不单独收缓存写入、存储或工具费用。此处是平台公开收费标准，不是供应商精确成本或结算账单。
- 生图按每张单价扣额度；个人知识整理按整理模型 Token 扣额度。管理员发起的企业知识整理不扣用户额度。
- 流式用量取最终累计值，不相加。未返回完整用量的请求金额记为未知、不估算扣费。
- 订阅用户使用的模型必须确认人民币单价，未配置则明确提示，不能把未知价当免费。

金额内部使用百万分之一元整数；每个请求向上取整到百万分之一元。请求期间临时预占额度，最终按实际用量释放并结算。一个请求只结算一次；迟到响应归属发起时的套餐周期。套餐累计扣款不超过包含额度。

## 上线前数据清理范围

开发阶段的历史请求/Token 用量、开通申请和旧订阅记录可以清除，不迁移、不倒算金额。保留账号、Key、模型、知识库、收款信息及套餐定义，按新的金额表单重新设置套餐额度，并删除套餐数据中的旧 token_limit 字段。恢复服务前，为保留的普通账号重新开通默认套餐。

不新增迁移脚本，也不保留旧 Token 套餐格式的运行时兼容分支。后端和客户端需要配套更新；待管理员完成一键部署、客户端构建和发布后，再执行已授权的历史数据清理及套餐重新配置，不能在网关运行期间直接修改其数据库。
