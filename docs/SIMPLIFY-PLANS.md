# 套餐与模型选择精简

套餐仅使用总 Token 额度，token_limit 为 null 时不限额，为 0 时额度为零。保留套餐等级决定升级路线；不再设置套餐请求次数、每日/月度额度或并发数。账号请求统一排队执行，同一账号同时运行一个请求。

用户不再由后台指定默认模型，客户端记住自己的选择；不可用时在模型选择处提示，历史会话不自动替换模型。

## 已有数据库升级（v5 → v6）

本次代码不会自动清空或迁移数据库。应用新服务前，使用受保护环境变量 DB_PATH、KEY_ENCRYPTION_SECRET，正常停止网关，执行：

```sh
node scripts/simplify-plans.js
node scripts/simplify-plans.js --apply
```

命令在 apps/server 目录运行。第一条仅预览；第二条先生成加密 v5 备份，再在一个事务内修改。QCODE_MIGRATION_BACKUP 可指定独立备份路径，不覆盖现有文件。存在进行中的请求、密钥不正确、备份失败或数据不合法时拒绝修改。

旧总 Token 的 0 转为 null（保持原不限额含义）；正数保持不变。移除用户默认模型和并发字段，移除套餐与订单/订阅条款中的多余限额。保留用户、Key、模型、Skill、知识库、请求记录、订阅标识、开始/到期时间，不重新发放额度。请求次数仍可作为运行统计，但不作为套餐限制。

v4 数据库须先按 ADMIN-ACCOUNTS.md 执行 remove-departments.js 升至 v5，再执行本脚本。新服务仅读取 v6；回退时停止服务，使用上一版代码及加密 v5 备份恢复，勿让旧服务读取 v6。
