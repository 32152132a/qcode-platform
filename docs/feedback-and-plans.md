# 问题反馈与订阅套餐

## 问题反馈

员工客户端账号旁的反馈图标可提交联系电话、最多 1000 字描述和最多三张截图。手机号由用户自行填写，不做短信验证。PNG/JPEG/WebP 截图在客户端压缩为 JPEG，服务端校验类型及每张 256 KB 上限；每个账号每日最多提交五次，重复提交同一编号不会产生重复记录。

管理端“问题反馈”支持查看详情、回复、待处理/已采纳/不采纳/已完成状态以及删除。奖励由管理员另行手动发放，系统不承诺自动奖励。普通用户仅能查看自己的反馈；公开演示账号不能读取员工联系方式和截图。管理员截图预览使用 15 分钟有效的签名下载链接，不暴露会话 Token，不放开全局图片 CSP。

反馈与截图存入 SQLite，使用现有加密备份与恢复流程；旧数据库缺少新增集合时会在启动时建立表，旧备份仍可读取。

## 订阅套餐

套餐和管理员、演示账号、普通用户这些账号角色分开。管理员设置名称、价格、有效天数、使用额度和可选模型。使用额度以人民币计量，0 表示没有额度，不表示不限。完整规则及开发数据清理范围见 [套餐使用额度](CREDIT-BILLING.md)。

员工在“账号与套餐”查看账户、剩余额度、到期时间和套餐卡片。无套餐配置或从未开通过套餐的账户保留原有个人配置。员工提交的是开通申请，不是支付；当前没有在线支付、余额充值或自动扣款，管理员核对收款/免费开通后确认。

开通时保存价格和权益快照，编辑或下架套餐不会更改已经购买的权益。重新开通/变更会立即替换旧套餐并开始新周期，不顺延、不累加旧额度；界面会提示这一点，历史请求和旧开通记录保留。每次模型请求绑定开通记录，防止周期之间混算。审批同一申请不会重复开通。

已开通普通账号的对话模型由服务器过滤并校验，不能通过直接调用接口绕过；到期后仍可登录、提交反馈和申请开通，但不能继续发起模型请求。没有开通过套餐的旧账号保持原配置，管理员可通过已有账号配额控制试用范围。

模型固定单价用于平台计价，实际用量结算到当前套餐额度；它不等于供应商账单。支付仍由管理员人工核款，积分、支付回调、退款均未接入。生图/识图由管理员配置，生图按张计价，到期同样停止。

“已开通用户”支持切换套餐和重置额度。切换套餐重新开始有效期及额度；重置只恢复当前有效周期的额度，不改到期时间，不删除请求记录，处理中或已到期的周期不能重置。用户管理的已用金额和套餐总额度按当前周期展示。

## 验证与更新

服务端新增反馈和套餐测试已登记到 apps/server/test/run.js。管理端复用 PagePanel、DataTable、EntityDialog、qyq-form、qyq-table 及 Element Plus；用户端复用现有 React UI 组件。浏览器测试脚本通过 QCODE_TEST_PLAYWRIGHT_MODULE 指向本机已有的 Playwright，不连接真实模型。

先部署网关及管理端，再重新登录管理端加载新增菜单权限；用户端入口需重新构建安装包并更新。后续调整套餐不需要重新安装客户端，员工可点击“刷新权益”或重新打开工作台同步模型列表。
## 自助注册

桌面登录页提供注册入口，填写账号、密码和确认密码；注册成功后返回登录。
服务端仅创建普通用户，自动开通当前上架且免费的默认套餐；未配置该套餐时不允许注册。
客户端提交的角色、套餐、额度和设备上限不会用于注册。管理员与演示账号名称保留。
同一 IP 每 15 分钟最多提交 5 次注册请求。注册沿用现有密码加密，不新增数据库字段。
注册仅分配默认套餐，不接受用户提交的价格或额度。
